# 自定义主题设计

已确认：终端主题编辑器、独立界面主题及可选联动。

- 在终端配色中提供新建、复制、编辑、重命名和删除入口。
- 内置和社区主题只读；编辑自定义副本，保存时采用稳定 ID。
- 编辑器提供颜色选择器、HEX/RGB、背景/文字/光标/选区和 ANSI 16 色。
- 草稿独立于已应用配置；实时预览、展开预览、重置、保存和保存并应用。
- 预览包含提示符、日志、diff、色板、光标、选择及界面组件。
- 外观支持系统、深色、浅色、跟随终端、自定义。
- 自定义界面提供背景、面板、正文、次要文字、强调和边框颜色，自动派生交互状态。
- 高级设置允许覆盖派生颜色。
- 跟随终端时固定主题来源，不能依赖推导后的界面深浅色重新选择主题。
- 终端及界面背景分别设置不透明度，文字保持不透明。
- 延续已有背景图片和平台透明窗口能力，不承诺平台不支持的桌面透明。
- 新配置缺省保持旧行为，旧主题目录继续可读。
- 使用当前 Go/Viva 原生界面实现，无新增前端框架。
- 验证正常创建、复制、修改、取消、保存恢复、联动、已有终端刷新与可视化交互。
