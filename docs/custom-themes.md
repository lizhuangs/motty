# 自定义主题

## 终端主题

打开「设置 → 终端 → 终端配色」，在主题卡片上右键操作；完整主题列表同样支持右键菜单。

- 新建：点击配色列表标题旁的「新建主题」，可选择深色或浅色模板。
- 复制：复制右键点击的主题，不必先应用该主题。内置、社区及目录导入主题只提供复制。
- 编辑：修改右键点击的自定义主题，也可在编辑器中重命名。主题 ID 不随名称改变。
- 删除：确认后移除自定义主题，正在使用它的终端恢复默认配色。

编辑器支持背景、文字、光标、选区及 ANSI 16 色。点击任意色块立即打开颜色选择器，也可以点击「打开颜色选择器」；HEX、RGB 字段用于精确输入。背景不透明度只作用于底色，文字保持不透明。

编辑器顶部提供「最大化 / 还原」，最大化后占满应用窗口的可用区域。宽窗口并排显示编辑区和实时预览；窄窗口通过「编辑 / 预览」切换。展开预览可查看终端示例、色板及界面跟随效果。预览使用本地固定文本，不执行命令或连接服务器。

- 重置修改：恢复本次打开编辑器时的配色。
- 保存：保存主题；若正在使用该主题，现有终端同步刷新。
- 保存并应用：保存并选用该主题。
- 取消或关闭：丢弃草稿，不改变已保存的主题。

主题存入现有配置存储，随共享设置同步。原有 `schemes` 目录的 `.xresources` 文件仍可使用，编辑时创建独立副本。

## 界面主题

「设置 → 外观」支持系统、深色、浅色、跟随终端、自定义五种模式。

「跟随终端」以明确的终端主题为来源，派生标题栏、侧栏、正文、面板和状态色。在终端配色中切换主题时，界面同步改变。原有深浅色模式的终端选择保持保留。

「自定义」提供背景、面板、正文、次要文字、强调色、边框等颜色。高级颜色允许覆盖悬停、按下及标签页状态。颜色选择器内的草稿在点击应用后生效。

界面背景不透明度独立于终端背景；存在背景图片或平台提供透明窗口时生效。没有透明支持及背景图片时，界面维持可读的实色背景。主题编辑器和确认弹窗保持不透明。
